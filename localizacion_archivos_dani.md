# Localización de archivos

## Archivos de la arquitectura
Estos archivos están ubicados en la carpeta `config/cortexa57`.
```bash
cd config/cortexa57
```
## Microkernel
Las funciones del microkernel están ubicadas en el archivo C `blis/kernels/armv8a/3/bli_gemm_armv8a_asm_d6x8.c`. El siguiente promp es para moverte a la carpeta
``` bash
cd ./kernels/armv8a/3/
```
